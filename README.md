# YOUNG STAR BOYZ — Ganesh Puja Committee Website

A responsive single-page website for the YOUNG STAR BOYZ Ganesh Puja Committee, Binjharpur, Bachhol, Odisha. Plain HTML, CSS and JavaScript — open `index.html` in any browser. No build step needed.

## Sections

- Hero with a live countdown to Ganesh Chaturthi (Saturday, 4 September 2027, midnight IST)
- About us and values
- Ganesh Puja programme
- Ganesh mantra
- Contribution and contact

## Before publishing

Update these placeholders in `index.html`:

- `Contact number — to be added` (Contact section)
- `contact@example.com` (email link)

Programme timings marked "To be announced" can be updated once the committee confirms them. Confirm the local puja muhurat for your area before publishing worship timings.

## Change the countdown date

In `script.js`, edit `ganeshPujaTarget` (format `YYYY-MM-DDTHH:MM:SS+05:30`).

## Files

- `index.html` — content
- `style.css` — design (colours are defined at the top under `:root`)
- `script.js` — menu, scroll effects, footer year, countdown
